暂时没有自动列出任何指南

这通常是因为：1）你用了 file:// 直接双击打开本页，浏览器禁止读取同目录文件；2）或当前服务器没有开启目录列表。

解决办法（任选其一）：

  1. 在文件所在目录打开终端，运行 python3 -m http.server 8000，然后访问 http://localhost:8000/（推荐，能自动扫描）。
  2. 或直接编辑本文件顶部 const FILE_LIST = [...];，手动把文件名填进去（无需服务器也能用）。

🔧 「自动检索」是怎么工作的

  • 本页会先尝试用 fetch('./') 向服务器请求当前目录的列表，并把其中所有 .html 文件抓出来。
  • 如果能抓到 → 用自动模式（左上角显示绿色「自动检索」），以后新增 / 改名文件都会自动纳入。
  • 如果抓不到 → 自动切换为清单模式（左上角显示橙色「内置清单」），使用文件顶部 FILE_LIST 里的名单。
  • 每个卡片会自动尝试读取该页面的 <title> 作为标题；按文件名关键字匹配主题色和图标。

💡 用 python3 -m http.server 或任意支持「目录列表」的静态服务器托管，即可获得最完整的自动体验。
